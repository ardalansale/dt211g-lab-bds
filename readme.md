# Laboration 3, 4 and 5

## Live Site
[Click here to view the site](https://dt211g-lab-bds.netlify.app/)

## Features
- Website for my future design agency Boteh Design Studio
- Built with SASS using a structured file architecture with partials
- Light and dark theme support via media query
- Responsive design for both mobile and desktop
- Automatic image optimization at build time
- CSS animations using @keyframes, transition and transform
- Charts displaying admission statistics from MIUN HT2025 using Chart.js
- Interactive map with location search using Nominatim API and OpenStreetMap
- Data fetched from external sources using Fetch API with async/await
- JavaScript documented with JSDoc

## Technologies
- Vite
- SASS (SCSS)
- HTML, CSS, JavaScript
- Chart.js
- Nominatim API + OpenStreetMap
- vite-plugin-image-optimizer
- JSDoc
